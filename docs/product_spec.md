# 产品与分析设计

## 用户分析：为什么买

- 浏览、点击、收藏、加购、购买、退款的完整行为漏斗。
- 类目、品牌、价格带、颜色与风格偏好。
- 短期会话兴趣与长期历史兴趣。
- 价格敏感度：折扣响应、成交价格带、价格变化后的行为变化。
- RFM 用户分群、复购率、留存、流失风险和用户生命周期。
- 新用户冷启动：显式偏好问卷、场景信息与热门商品融合。

可视化：行为漏斗图、兴趣雷达图、用户分群散点图、价格带分布、活跃度与转化率趋势、留存热力图。

## 商品分析：什么值得推荐

- 标题、类目、品牌、价格、属性、图片和商品描述质量。
- 热度、点击率、加购率、转化率、退款率和库存状态。
- 新品与长尾商品曝光，热门集中度和商品覆盖率。
- 商品相似度、搭配关系与替代关系。
- 图像颜色、风格、材质及图文一致性。
- 价格、库存、上下架状态变化对推荐结果的影响。

可视化：品类销量图、价格—转化率散点图、长尾分布、商品漏斗、品牌矩阵、相似商品网络。

## 场景分析：什么时候、为什么推荐

- 时间、季节、天气和节假日。
- 通勤、旅行、送礼、宿舍、运动等使用场景。
- 当前预算、促销活动、库存和配送时效。
- 搜索词、当前会话上下文和历史偏好冲突。
- 不同入口、设备和地域下的行为差异。

可视化：场景转化率、时段热力图、预算匹配率、场景—品类矩阵和渠道对比。

## Bad Case 分类

- 超出预算或违反排除条件。
- 品类、尺寸、颜色或使用场景错误。
- 推荐结果同质化、热门挤压长尾商品。
- 图片相似但商品语义不一致。
- 推荐理由引用不存在的商品属性。
- 新用户结果过于泛化。
- 推荐下架、缺货或不可配送商品。
