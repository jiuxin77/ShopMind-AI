# M8 AI 导购需求理解报告

## 功能链路

```text
自然语言需求
  → 品类/预算/场景/风格/排除项抽取
  → BM25 + TF-IDF + 热门召回
  → 库存、上下架、品类、预算和排除条件过滤
  → Top-K 商品
  → 基于商品事实与召回证据生成推荐理由
```

实现采用确定性规则解析器，因此无需外部模型、网络请求或 API Key，适合本地演示和自动化回归。接口为 `POST /shopping-assistant`，Streamlit 的“4 AI 导购”页提供完整交互。

## 示例

输入：`想买一款通勤用的简约女装，预算500元以内，不要星野品牌`

结构化输出：

- 品类：女装
- 预算上限：500 元
- 场景：通勤
- 风格：简约
- 排除：星野

每条推荐理由只引用可验证事实，例如商品价格、预算是否满足及 `popular#7`、`bm25#12` 等召回证据，不让生成文本虚构商品属性。

| 指标 | 结果 |

该测试集为人工设计的小规模功能回归集，只覆盖项目当前支持的表达方式，不代表开放域语言理解的泛化准确率。后续可扩充同义表达、否定歧义、复合预算和多轮澄清案例。
