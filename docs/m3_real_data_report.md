# M3 真实电商数据召回实验

## 数据来源

实验使用 UCI Machine Learning Repository 的 **Online Retail** 数据集，包含英国线上零售商在 2010—2011 年间的 541,909 条交易记录。

- DOI：`10.24432/C5BW33`
- 许可：CC BY 4.0
- 官方页面：https://archive.ics.uci.edu/dataset/352/online+retail

清洗规则包括：删除缺失客户或商品描述的记录、取消订单、数量非正记录和价格非正记录。为控制本地实验成本，选择交易最活跃的 300 名用户和最高频的 800 件商品，得到 113,218 条购买行为。

## 模型

- Popular：全局热门召回。
- ItemCF：基于用户共同购买的商品协同过滤。
- Text Vector：商品描述字符 n-gram TF-IDF 向量召回。
- Hybrid：Popular、ItemCF、BM25 与 Text Vector，通过 RRF 融合。

## 50 用户阶段性结果

| 模型 | HitRate@10 | NDCG@10 | 商品覆盖率 | P95 延迟 |
|---|---:|---:|---:|---:|
| Popular | 2.0% | 0.0200 | 1.25% | 16.99 ms |
| ItemCF | 2.0% | 0.0058 | 8.63% | 147.98 ms |
| Text Vector | 2.0% | 0.0063 | 43.38% | 23.24 ms |
| Hybrid | **4.0%** | **0.0300** | 27.13% | 185.17 ms |

## 结论与限制

- 混合召回在当前样本中命中率是单路模型的两倍，同时维持比热门模型更高的商品覆盖率。
- 文本向量召回显著扩大商品覆盖范围，适合缓解热门商品集中问题。
- 当前 ItemCF 在每次请求中重建共现关系，延迟偏高；下一步应离线预计算相似度并缓存。
- 50 名用户样本不足以支持统计显著性结论，后续需扩大样本、固定随机种子并进行置信区间或 Bootstrap 检验。
