# M9 轻量级视觉检索报告

## 定位

本阶段实现一个无需下载模型权重的视觉检索工程基线，用于展示图片预处理、向量化、索引、相似度搜索、鲁棒性评测和前端交互的完整链路。

商品图是代码生成的确定性合成缩略图，不是真实商品照片；模型是手工视觉特征，不是 CLIP。项目页面会显式展示这一限制。

## 特征与检索

- Hue/Saturation 直方图：描述全局颜色分布并降低亮度影响。
- RGB 色度比例：保留 4×4 空间颜色布局，同时对整体亮度变化保持稳定。
- 归一化边缘：补充轮廓和纹理信息。
- 检索：向量 L2 归一化后使用余弦相似度返回 Top-K。

## 亮度扰动评测

从 100 个演示商品中选择前 50 个，将查询图亮度调整为原图的 0.72、0.86、1.14 或 1.28 倍，再从完整索引中检索原商品。

| 指标 | 结果 |
| --- | ---: |
| 查询数 | 50 |
| Top-1 准确率 | 100% |
| Top-5 准确率 | 100% |

该结果说明特征对测试范围内的整体亮度变化稳定。它不覆盖真实背景、视角、遮挡、裁剪或跨模态语义，下一阶段接入真实授权图片与 CLIP 后必须重新建立独立评测集。
