# M2 多路召回基线报告

## 实验设置

- 数据：`synthetic-demo-v1`，300 名用户、200 件商品、5000 条随机模拟行为。
- 召回：热门召回、ItemCF、BM25。
- 融合：Reciprocal Rank Fusion（RRF）。
- 过滤：库存、上下架、品类和预算约束。
- 切分：每位符合条件用户保留最后一次正向行为作为测试目标。
- 评测：100 名用户，`K=10`。

## 首轮结果

| 指标 | 结果 |
|---|---:|
| Precision@10 | 0.005 |
| Recall@10 / HitRate@10 | 0.050 |
| NDCG@10 | 0.0199 |
| 商品覆盖率 | 24.0% |
| 平均延迟 | 5.96 ms |
| P95 延迟 | 6.36 ms |

## 结论

这组数据的用户—商品行为是随机生成的，缺少稳定兴趣关联，因此不能用来证明推荐质量提升。它目前用于验证召回、融合、过滤、评测和性能记录链路是否完整。

下一步需要引入包含真实用户行为序列的公开数据集，并分别运行热门、ItemCF、BM25 和融合模型，做基线对比与消融实验。
